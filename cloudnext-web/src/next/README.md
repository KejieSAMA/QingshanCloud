## 当前改造状态

本次源码已将新版提升为唯一 PC 界面。2026-09-14 已按授权编译并重启 API，8088 健康检查为 UP；前端沿用现有 5174 Vite 服务，本轮未执行前端生产构建或重启。手机页面和认证功能保留，UI 由人工验收，不使用 Computer Use。

## 入口与路由

- 一个 Vue 应用、一个 History 路由，主入口为 index.html，桌面首页为 /。
- 登录成功、401 后重新登录及退出均使用应用内路由；只有 Form 跨系统认证仍需要浏览器导航。
- next.html 是同应用兼容 HTML，不是第二个应用。历史 next.html#/... 在启动前通过 replaceState 原地转成普通路径，保留目录、共享、空间与搜索参数。
- 手机断点为 559px；560px 及以上使用桌面响应式界面。切换尺寸不刷新页面。
- 旧 PC 外壳、旧桌面表格和版本切换入口已删除；Git 历史仍可回溯。
- 手机视图移到 src/mobile/pages；仍被手机使用的共享弹窗、管理页面及工具保留。独立 Office 预览路径不变。

## 主题与样式

默认商务蓝 #3264d8、紧凑密度、列表；已有绿色偏好保留。前端初值、登录页、恢复默认和后端缺省值均为蓝色。沿用 next.ui.* 偏好键，无数据库结构或数据迁移。

原始 Demo 副本保存在 reference/demo-v3.1.html，未修改。桌面 CSS 仅增加场景作用域，原始声明值保持一致。手机样式从旧样式中提取并限制在 mobile 场景；独立预览只使用必要中性规则。应用级弹窗容器支持跨布局显示与主题预览。

桌面登录页使用 Demo 的字体、蓝色、输入框、按钮与图标风格，不导入旧 PC CSS。桌面与手机表单共用一个登录控制器，尺寸切换不会再次消费 SSO bootstrap。

## 会话与传输

上传队列、冲突对话框、Office 预览与会话状态由主应用托管。个人盘和空间上传均记录提交时的目标，切页/切换布局不终止任务；退出确认后中断尚未完成的上传。

退出或更换 token 会清理用户数据、权限、偏好、弹窗、预览和队列。迟到的上一会话响应被丢弃，旧请求的 401 不会注销新账号。已完成的服务端写入不因清理本地状态而回滚。
