# 统一入口交接

一个主应用负责会话、路由、响应式布局及传输生命周期。AdaptivePage 按 559px 断点选择手机/桌面页面；LoginRoute 在布局切换时保留同一个登录控制器。

历史路径规范化由 authNavigation 完成；账号变化清理由 next/state 完成；请求返回时由共享 API 检查 token 是否仍一致。不同账号的旧异步任务不能更新新界面或继续排队上传。

桌面默认蓝色，后端保留 next.ui.* 参数接口与持久化数据。仅缺省值从 green 改为 blue，不执行迁移或覆盖已有偏好。

验证方式和人工清单见 README.md。2026-09-14 API 已编译重启，5 项后端测试通过；前端仍沿用 Vite 源码服务，未执行新的前端生产构建或 UI 验收。
